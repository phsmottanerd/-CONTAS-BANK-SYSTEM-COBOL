# 🚀 Sobre o Projeto

```diff
+ Sistema bancário desenvolvido em COBOL com foco no aprendizado dos
+ fundamentos da programação estruturada, manipulação de dados e
+ construção de aplicações corporativas.

+ O projeto simula operações bancárias básicas permitindo a criação,
+ consulta, alteração e exclusão de contas.

+ Este sistema demonstra conhecimentos em lógica de programação,
+ estruturas condicionais, entrada e saída de dados e organização
+ de aplicações em COBOL.

+ Desenvolvido com foco em boas práticas, legibilidade de código
+ e compreensão dos conceitos utilizados em sistemas legados
+ amplamente presentes no mercado financeiro.
```
